The NVKE controller is last to become Ready: it blocks on "no identity issued"
until SPIRE has issued its SVID, and its /readyz reports PostgreSQL and
Temporal, so it will not pass until both are up. A helm --wait that has already
returned does not mean it got there.

  kubectl -n {{ .Values.nvke.namespaces.controller }} rollout status deployment/nke-controller --timeout=10m

CAPNICo is not installed, so nothing reconciles NicoCluster or NicoMachine.
It is a Cluster API provider, not a chart here:

  clusterctl init --infrastructure nico:<version> --config ./clusterctl.yaml \
    --wait-providers

Then create the credentials Secret CAPNICo reads:

  kubectl create secret generic nico-credentials -n capnico-system \
    --from-literal=endpoint=<nico-api-base-url> --from-literal=orgID=<org> \
    --from-literal=apiName=<api> --from-literal=token=<token>
